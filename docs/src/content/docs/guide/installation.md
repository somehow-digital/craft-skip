## Requirements

- Craft CMS 5.8.0 or later
- PHP 8.2 or later

## Install

Install the plugin from the [**Plugin Store**](https://plugins.craftcms.com/skip) in the Control Panel, or with [Composer](https://packagist.org/packages/somehow-digital/craft-skip):

```bash
composer require somehow-digital/craft-skip
php craft plugin/install skip
```
